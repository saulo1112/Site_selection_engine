# Results v1 — MCDA baseline

_Generated by `src/models/mcda.py`. Total hexagons: **3589**._

## What is this version

Weighted, **interpretable** score, no ML: min-max normalization per feature and a linear combination with a priori weights defined through business reasoning (not fitted to the label). It is the **baseline** against which v2 (look-alike classifier) and v3 (spatial CV) will be measured.

## Anti-leakage

Features derived from D1's location (`n_d1_300m`, `n_d1_500m`, `dist_d1_km`) are **excluded from the score**: the `tiene_d1` label is defined as `n_d1_300m >= 1`, so using them would be tautological leakage. The label is used **only afterward**, as an honest validation (ranking metrics below), never as a score input.

> **Note:** the demographic features (`poblacion_estimada`, `viviendas_estimadas`) are not available in this run (DANE census not loaded, see `src/data/load_censo.py`). Their group weight was redistributed proportionally among the present groups.

## Honest post-hoc evaluation (ranking vs. `tiene_d1`)

These metrics were **not** used to choose the weights; they only measure, after the fact, how well the MCDA ranking recovers the cells where D1 is already present.

- **NDCG@200**: 0.8033 (quality of the top-K ordering; 1.0 = perfect).
- **Precision@200**: 0.7650 (153 of the top 200 ranked cells already have D1).
- **top-200 hitting** (recall of positives in the top-K): 0.1741 (ceiling = 0.2275, because there are 879 positives > K=200: not even a perfect ranking can capture them all in only K cells).
- **top-200 loss** (positives outside the top-K): 0.8259
- Positives in the top-200: **153** out of 879 total positives (3589 hexagons).

> **Honest reading:** the `hitting` value looks low only because there are far more positives (879) than selected cells (K=200). The more informative metric here is **Precision@200 = 0.765** and **NDCG@200 = 0.803**: an ML-free baseline that ranks the cells most similar to D1's reasonably well. v2/v3 should beat it (or, in v3, reveal how much of this was spatial leakage).

## Limitation

The score reflects **similarity / exploration priority**, not performance: it measures resemblance to cells where D1 already operates, not expected sales. It inherits the look-alike assumption that D1's location strategy is good (see docs/metodologia.md §5).
