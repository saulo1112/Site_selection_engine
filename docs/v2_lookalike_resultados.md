# Results v2 — Look-alike classifier (Logistic Regression)

_Generated by `src/models/lookalike.py`. Total hexagons: **3589**._

## Classes to predict

**Binary** classification on the `tiene_d1` label (computed in STAGE 4):

- **Class 1 (positive, ~24.5%):** the hexagon ALREADY has >=1 D1 store within <=300m ("D1-type cell", a site D1 has already chosen).
- **Class 0 (negative):** the hexagon has no nearby D1.

The model estimates `P(class=1)` from the **non-D1** features, and that probability is the **look-alike score** used to rank the hexagons.

## Predictors (anti-leakage)

**7** features are used: `n_supermercados_500m`, `dist_supermercado_km`, `n_farmacias_500m`, `n_colegios_500m`, `n_paradas_bus_500m`, `n_bancos_atm_500m`, `densidad_vial`.

The features derived from D1 (`n_d1_300m`, `n_d1_500m`, `dist_d1_km`) are **excluded**: the label is a direct function of them, using them would be tautological leakage.
The demographic features (`poblacion_estimada`, `viviendas_estimadas`) are not available (DANE census not loaded, see `src/data/load_censo.py`) and are left out.

## Split (v2 = random split, naive)

**Random stratified** split 75/25 (`random_state=42`). **Warning:** the random split distributes neighboring (spatially autocorrelated) hexagons between train and test, so the metrics are likely **inflated by spatial leakage**. v3 corrects this with spatial CV and compares (see docs/metodologia.md §6).

## Limitation

**Positive-unlabeled** problem: the negatives include good sites where D1 has not yet arrived. The score reflects **similarity / exploration priority**, not performance; it inherits the assumption that D1's location strategy is good (docs/metodologia.md §5).
