# Deployment — serving architecture and live demo

## Stack decision

**Hybrid FastAPI (serving) + Streamlit/pydeck (UI), with a live demo.** Single-component
alternatives were discarded: a pure Streamlit UI does not demonstrate a service layer, and a
custom JS frontend + Kepler.gl adds maintenance overhead without adding value for the
portfolio objective. The hybrid demonstrates API/UI separation without writing custom JS frontend.

## Guiding principle: serving decoupled from PostGIS

PostGIS is a **local ETL** dependency (feature computation in `src/data/`), **not** a
runtime one. The API serves from **versioned artifacts** generated by the pipeline:

| Artifact | Generated by | Used by |
|---|---|---|
| `data/processed/lookalike_v*_ranking.parquet` | `src/models/lookalike_v*.py` | API `/hexes`, `/hex` |
| `data/processed/lookalike_v*.joblib` | same | API `/score` (live inference) |
| `data/processed/features.parquet` | `src/data/features.py` | API `/hex` (detail), `/score` by h3 |
| `data/raw/pois_*.geojson` | `src/data/download.py` | API `/pois/{name}` (overlays) |

This allows both services to be hosted cheaply (no managed database). The artifacts are
small (KB) and are versioned (exceptions in `.gitignore`); see
"Versioned serving artifacts" below.

## Components

```
                 ┌─────────────────────────┐
   browser ─────▶│ Streamlit Cloud (UI)    │   app/streamlit_app.py
                 │  pydeck H3HexagonLayer   │   (map, filters, overlays)
                 └───────────┬─────────────┘
                             │ HTTP (API_BASE_URL, secret)
                             ▼
                 ┌─────────────────────────┐
                 │ FastAPI (Render/HF)      │   src/api/main.py
                 │  /hexes /hex /score /pois│   reads versioned artifacts
                 └─────────────────────────┘
                             ▲
                             │ (build-time, local)
                 ┌─────────────────────────┐
                 │ Local ETL + PostGIS      │   src/data/* (docker-compose)
                 │  generates the artifacts │   src/models/*
                 └─────────────────────────┘
```

**Robustness fallback:** if `API_BASE_URL` is not configured or the API is unresponsive,
the Streamlit app reads the local parquet files directly (`src/api/service.py`), so that
the demo runs in a single process without the API.

## API endpoints

| Method | Route | Description |
|---|---|---|
| GET | `/health` | Status + available models + number of hexagons |
| GET | `/models` | Models with precomputed ranking |
| GET | `/hexes?model=&top_k=&min_score=&bbox=` | Ranked hexagons (map) |
| GET | `/hex/{h3_index}?model=` | Detail: score, rank, features, ring geometry |
| POST | `/score` | Live inference with the `.joblib` (by `h3_index` or `features`) |
| GET | `/pois/{name}` | GeoJSON of POIs (`d1`/`competidores`/`complementarios`) |

`SERVING_MODEL` (env) sets the default model (`v3` until demographics are loaded; `v4`
afterward). Interactive docs at `/docs`.

## Running locally

```bash
uv sync
# API
uv run uvicorn src.api.main:app --reload          # http://127.0.0.1:8000/docs
# UI (in another terminal). Without API_BASE_URL it uses the local parquet fallback.
API_BASE_URL=http://127.0.0.1:8000 uv run streamlit run app/streamlit_app.py
```

## Live demo

### API → Render (free tier) or Hugging Face Spaces (Docker)
- `Dockerfile` installs only serving dependencies (without osmnx/geopandas/PostGIS) →
  lightweight image. Copies `src/`, `data/processed/` and `data/raw/pois_*.geojson`.
- Render: use `render.yaml` (blueprint). Health check at `/health`. Injects `$PORT`.
- HF Spaces: create a *Docker*-type Space; it exposes the `CMD`'s port.

### UI → Streamlit Community Cloud
- Main app: `app/streamlit_app.py`.
- Secret `API_BASE_URL` = public URL of the API (see `.streamlit/secrets.toml.example`).
- On the API, set `SERVING_CORS_ORIGINS` to the Streamlit app's domain.

## Versioned serving artifacts

`data/processed/*` and `data/raw/*` are in `.gitignore`, but the serving artifacts
(parquet rankings, `.joblib`, `pois_*.geojson`) are explicitly **excepted** so that
the Docker image and Streamlit Cloud run without executing the ETL. They are KB-sized. If in the
future they grow, migrate to a *release asset* downloaded at the API's `startup`.

## What is NOT needed in production

`docker-compose.yml` (PostGIS) and the heavy dependencies (`osmnx`, `geopandas`,
`psycopg2`) are only for regenerating features/artifacts locally. The API and the UI do not
require them.
