# Results v3 — Look-alike classifier with Spatial CV

_Generated by `src/models/lookalike_v3.py`. Total hexagons: **3589**._

## What changes relative to v2

**Same model** (Logistic Regression), **same class definition** (class 1 = cell with D1 within <=300m). The only thing that changes is the **validation**: instead of a random split, **spatial** cross-validation. Each hexagon is predicted *out-of-fold* (OOF) by a model that did not see its neighborhood -> an honest estimate of how the model generalizes to new areas of the city.

## Spatial CV scheme (anti spatial-leakage)

- **Spatial blocks**: H3 parent at resolution **6** -> 24 blocks (~36 km2 each). Whole blocks go to train or test.
- **Folds**: StratifiedGroupKFold, **5** folds (respects blocks, balances positives).
- **Buffer**: cells within <=**1** H3 ring(s) of any test cell are excluded from train.
- **Predictors** (leakage-free): `n_supermercados_500m`, `dist_supermercado_km`, `n_farmacias_500m`, `n_colegios_500m`, `n_paradas_bus_500m`, `n_bancos_atm_500m`, `densidad_vial`.

## Leakage verdict — v2 (random split) vs v3 (spatial CV)

| Metric | v2 random | v3 spatial CV | Δ (v3 - v2) |
|---|---|---|---|
| ROC-AUC (test/OOF) | 0.7801 | 0.7934 | +0.0132 |
| PR-AUC (test/OOF) | 0.5970 | 0.5899 | -0.0071 |
| NDCG@200 | 0.8349 | 0.8400 | +0.0051 |
| top-200 hitting | 0.1832 | 0.1854 | +0.0023 |

> **Verdict:** performance **holds up** under spatial CV (Δ NDCG@K +0.0051, Δ ROC-AUC +0.0132; v3 even matches or slightly exceeds v2). Spatial-autocorrelation leakage turned out to be **smaller than expected**: with a linear model over buffer features (smooth spatial fields), a random split and a spatial one generalize similarly. This is a valid and honest finding — the non-D1 signal (competitors/complementary/road) holds up in unseen areas, it was not a mirage of the split.

## Limitation

Still a score of **similarity / exploration priority** (not performance), with the look-alike assumption that D1's location strategy is good (docs/metodologia.md §5). Spatial CV corrects spatial leakage, not the biases of the proxy or of OSM tagging.
